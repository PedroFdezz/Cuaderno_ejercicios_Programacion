📓 Cuaderno de Programación – DAW

Ejercicios de la asignatura de **Programación** del ciclo de **Desarrollo de Aplicaciones Web (DAW)**, resueltos en **Java** con **IntelliJ IDEA**.

Este repositorio funciona como un cuaderno de aprendizaje: cada ejercicio es una clase independiente y cada commit refleja un paso del proceso, incluidas las correcciones.

---

## 🗂️ Estructura

```
src/
├── T1E01.java   → Tema 1, ejercicio 1
├── T1E02.java
├── ...
└── T5E10.java   → Tema 5, ejercicio 10
```

---

## 📚 Temas

| Tema | Contenido | Conceptos |
|:---:|---|---|
| 1 | Introducción a la programación | Estructura de un programa, sintaxis y semántica, entrada-proceso-salida, pseudocódigo, diagramas de flujo, eficiencia y depuración |
| 2 | Elementos de un programa | Tipos de datos, variables y constantes, operadores, casting y `Scanner` |
| 3 | Programación estructurada | `if`/`else`, `switch`, operador ternario, `for`, `while` y `do-while` |
| 4 | Programación modular | Procedimientos y funciones, paso por valor y por referencia, ámbito de variables y sobrecarga |
| 5 | Recursividad | Caso base, drivers, recursividad directa, indirecta y múltiple |

## ▶️ Cómo ejecutarlos

**Con IntelliJ IDEA:**
1. Clona el repositorio: `git clone <url-del-repo>`.
2. Ábrelo en IntelliJ con **File → Open**.
3. Abre cualquier ejercicio de `src/` y pulsa ▶️ junto al `main`.

**Desde la terminal:**
```bash
cd src
javac T1E04.java
java T1E04
```

---

## ✍️ Convenciones

- Variables y métodos en **camelCase**: `minutosTotales`, `calcularTotal()`.
- Clases en **PascalCase**: `T1E04`.
- Constantes en **MAYÚSCULAS** y con `final`: `final double PI = 3.14159;`.
- Un commit por ejercicio, con el formato `T1E06: descripción breve`.
